# คำสั่งสำหรับ Codex

นำฐานข้อมูลใน `src/data/league.json` เป็น **แหล่งข้อมูลหลักเพียงจุดเดียว** ของเว็บไซต์
NEW LIFE CHAMPION LEAGUE U18 2026

## งานที่ต้องทำ

1. ตรวจ repository ก่อน หากเป็น Next.js ให้รักษาโครงสร้างเดิม
2. เชื่อมข้อมูลผ่าน `src/data/index.ts`
3. ห้ามคัดลอกข้อมูลไป hard-code ซ้ำใน component
4. ตารางคะแนนต้องคำนวณจาก `matches` ด้วย `calculateStandings`
5. ดาวซัลโวต้องคำนวณจาก `goalEvents` ด้วย `calculateScorers`
6. ใบเหลืองรายบุคคลต้องคำนวณจาก `disciplineEvents`
7. โทษแบนต้องอ่านจาก `suspensions` โดยแยก:
   - pending_service
   - served
   - pending_decision
8. รองรับผู้เล่นเปลี่ยนหมายเลข โดยใช้ชื่อ/ID เดิม:
   - กันต์กวิน เอี่ยมสำอางค์: เดิม 67 ปัจจุบัน 50
   - วริท รุ่งเรือง: วีก 2 เบอร์ 25, วีก 4 เบอร์ 12
9. ไม่สร้างหรือใช้โลโก้โรงเรียนจนกว่าจะมีไฟล์ที่ตรวจสอบแล้ว
10. แสดงคำเตือนข้อมูลไม่สมบูรณ์จาก `dataQuality.knownMissingOrUnconfirmed`
11. รัน test, lint และ build แล้วแก้ error ก่อนสรุปงาน
